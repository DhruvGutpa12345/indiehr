# Routes that may answer 2xx to an anonymous GET on a tenant host (TENANCY_DESIGN.md §6.6).
# One route per line: "/" + the route regex exactly as Django lists it ("/" alone = site root).
# Each needs a reason. The isolation suite fails on any anonymous 2xx not listed here
# (fail-closed), so new upstream routes cannot become public unnoticed.
# Reviewed 2026-11-06 (P1-T1b). All are same-tenant only: none returns another tenant's data.
# FOLLOW-UP marks routes that stay public for now but need hardening (see TRACKER).
